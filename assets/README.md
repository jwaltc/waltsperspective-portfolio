# Assets

This folder holds all media for the portfolio site. Structure below.

---

## client-work/
Portfolio pieces from paid client projects. Each subfolder = one client.
Drop in the video file + a thumbnail image (ideally a 9:16 JPG/PNG pulled from the best frame).

- **sam-business/** — Sam's business content
- **jim-political/** — Jim's political content
- **matt/** — Matt's content
- **todd-spiritual/** — Todd's spiritual/faith content
- **irish-pub/** — Irish pub client content

### Naming convention
```
[client-slug]-thumbnail.jpg
[client-slug]-edit.mp4
```

---

## personal-work/
Self-directed projects and creative experiments. Same structure as client-work.

- **edm-promo/** — EDM promo edit
- **philosophy-talking-head/** — Philosophy talking-head piece
- **tree-video/** — Tree video / nature edit

---

## ambient-loops/
Short muted video clips (2–5 seconds) used as background texture in the parallax strips between page sections. These are NOT portfolio pieces — they're visual design elements.

Expected files:
- `ambient-1.mp4` — used in the first parallax strip (between About and Portfolio)
- `ambient-2.mp4` — used in the second parallax strip (between Portfolio and Testimonials)

Keep clips short, seamlessly loopable, and cinematic. No audio needed.

---

## testimonials/
Optional: screenshots of Upwork reviews or client messages to reference when writing the testimonial copy. Nothing is served directly from this folder in the site.

---

## images/
Auto-generated placeholder assets live here (e.g. `thumb-placeholder.svg`). Real thumbnails for portfolio cards should go in the relevant client/personal subfolder, not here.
